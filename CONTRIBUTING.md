# Contributing

Thanks for helping improve **Awesome Open Source Games**! 🎮

This is a curated index, so every entry should add real value.

## Add a project

Before submitting:

1. **Check for duplicates.**
2. Prefer the **official project/source repository**.
3. Make sure the project is genuinely open-source or clearly qualifies for the collection.
4. Write an accurate, neutral description in your own words.
5. Avoid copying substantial text from another README or curated list.
6. Check the project's own licensing and attribution requirements.
7. Use the most specific category available.
8. Make sure the URL works.

## Entry format

```md
- **[Project Name](PROJECT_URL)** — A concise description explaining why it is useful or interesting.
```

## Pull requests

Keep PRs focused. A good PR:

- explains what changed;
- adds or updates only relevant entries;
- preserves alphabetical/category organization where practical;
- does not introduce unrelated formatting changes;
- passes the repository's automated checks.

## Quality over quantity

A short list of excellent projects is better than a giant list of broken, duplicated, or low-value links.

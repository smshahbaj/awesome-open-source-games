# Project Scope

## Included

This collection focuses on:

- Open-source games
- Open-source game engines and frameworks
- Game-development libraries and tools
- High-quality source-code examples
- Educational resources directly useful for game development

## Excluded

Generally avoid:

- Closed-source games with merely public modding APIs
- Commercial software without an open-source license
- Link farms and low-value aggregations
- Duplicate projects
- Unrelated programming resources

When the status of a project is ambiguous, prefer linking to the project's own licensing page and avoid making an unsupported claim.


## Classification

Entries are grouped into four practical buckets: standalone games, classic reimplementations/source ports, development engines/frameworks, and supporting tools/libraries. Historical projects may remain when they have preservation or educational value; they should not be presented as actively maintained without evidence.

# Maintenance Guide

This repository is an index, not a mirror.

## Review an entry

- Confirm the URL still resolves.
- Prefer the project's canonical repository.
- Confirm the description is still accurate.
- Avoid outdated licensing claims unless verified.
- Remove duplicates.
- Replace moved repositories with the canonical location.
- Remove projects that no longer meet the collection's scope.
- Keep categories useful and descriptions short.

## Link policy

Use official project URLs where practical. Mirrors may be included only when they are the project's recognized canonical development location.

## Release discipline

For meaningful list changes:

1. Update the relevant documentation.
2. Run the Markdown and link checks.
3. Review the rendered README.
4. Keep commits focused and descriptive.

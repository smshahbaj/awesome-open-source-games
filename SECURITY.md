# Security Policy

## Scope

This repository is primarily a curated index and does not execute the software it links to.

## Reporting a problem in this repository

Please do not publish sensitive vulnerability details in a public issue.

Contact the maintainer privately through the contact method listed on the GitHub profile.

## Third-party projects

If you find a vulnerability in a project listed here, report it directly to that project's maintainers using their official security policy or private reporting mechanism.

This repository cannot accept or fix vulnerabilities in unrelated third-party software.

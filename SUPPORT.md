# Support

This repository is a curated directory, not a support channel for the individual projects it lists.

## For a listed project

Please use that project's official issue tracker, discussions, documentation, or community channels.

## For this collection

- Report broken/outdated information with the **Broken or outdated entry** issue template.
- Suggest a project with the **Project suggestion** issue template.
- For general improvements, open a GitHub issue with enough context to understand the proposal.
